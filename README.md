# MacVolumeControl

외부 컨트롤러의 볼륨 입력을 macOS 미세 볼륨 조정으로 바꿔 주는 메뉴 바 앱이다.

## 지원 입력

- `F11` / `F12`
- macOS 볼륨 미디어 키 이벤트

## 동작 방식

- 기본값은 `미세 조정 사용` 켜짐
- 지원 입력을 가로채서 macOS `Option + Shift + F11/F12`와 같은 미세 볼륨 조정 이벤트로 재전송
- `미세 조정 사용`을 끄면 원래 입력을 그대로 통과

## 빌드

```bash
swift build
```

앱 번들 생성:

```bash
./scripts/build-app.sh
```

생성 결과:

- `build/MacVolumeControl.app`

## 설치 및 실행

권한이 안정적으로 유지되게 하려면 앱 번들을 고정 경로로 옮겨서 쓰는 편이 낫다.

```bash
cp -R build/MacVolumeControl.app ~/Applications/
open ~/Applications/MacVolumeControl.app
```

바로 테스트만 할 때:

```bash
open build/MacVolumeControl.app
```

## 권한

글로벌 볼륨 키 입력을 가로채려면 macOS 손쉬운 사용 권한이 필요할 수 있다.

- 앱 메뉴에서 `권한 설정 열기…` 선택
- 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 허용
- 필요하면 `입력 모니터링`에도 같은 앱을 추가
- 허용 후 `입력 감시 다시 시작` 선택

## 메뉴 항목

- `현재 볼륨`: 현재 기본 출력 장치 볼륨 표시
- `입력 감시 상태`: 활성 / 권한 필요 / 꺼짐 표시
- `마지막 감지`: 앱이 마지막으로 가로챈 입력 표시
- `미세 조정 사용`: 시스템 미세 볼륨 조절 on/off
- `입력 감시 다시 시작`: 권한 허용 뒤 훅 재시작

## 문제 해결

- `입력 감시 상태: 권한 필요`가 계속 나오면 앱을 `~/Applications` 같은 고정 경로로 옮긴 뒤 권한을 다시 부여
- `마지막 감지`가 바뀌지 않으면 컨트롤러 입력이 이 앱까지 오지 않는 상태
- `마지막 감지`는 바뀌는데 볼륨이 안 움직이면 macOS 권한 또는 입력 종류 해석 문제를 다시 확인
